# ⚡ AI Daily Report · AI 行业每日简报

> 一份**有主张的编辑型单页日报**，**零依赖、可直接双击打开**。
> 原生 HTML + CSS + JavaScript，无构建、无 CDN、无外部库、不引字体文件。
> 以「时间轴叙事」组织今日 5 条前沿资讯，锚点色（电光紫）+ 衬线标题构建杂志式编辑感，清爽、前卫而不厚重。

---

## 一、项目简介

`index.html` 是一个**单文件、零外部依赖**的 AI 行业日报看板。它刻意做成「编辑产品」而非仪表盘：

- **新闻是绝对主体**——首屏即标题 + 今日速览目录 + 第一条时间轴资讯，无需滚动即可进入内容。
- **时间轴叙事**——5 条资讯按发生时间（08:30 → 15:10）纵向排列，左侧时间刻度、右侧内容卡片，比卡片堆叠更贴合「日报按时间发生」的语义。
- **编辑视角**——每条新闻在摘要之外给一行视觉明确区分的编者按（斜体 + 左侧色条 + 小标签），是内容层的差异化。
- **锚点色体系**——单一高对比电光紫只用在关键位置（主标题渐变、时间轴节点、阅读按钮、进度点、激活态），替代大面积低饱和 pastel。

## 二、功能介绍

### 核心阅读体验
| 功能 | 说明 |
| --- | --- |
| 今日速览目录 | 首屏 5 条极简条目（序号 + 一句话 + 领域点 + 热度点），点击直接打开弹窗，相当于日报目录 |
| 纵向时间轴 | 5 条资讯按 `time` 从早到晚排列，左侧时间刻度 + 节点，右侧内容卡片 |
| 热度可视化 | 每张新闻卡片内置迷你热度条 + 热度指数，扫一眼即知哪条最热 |
| 编辑视角 | 每条新闻一行编者按（斜体 + 左色条 + 小标签），与摘要区分 |
| 详情弹窗 | 点击时间轴节点 / 卡片 / 速览任一入口打开；顶部「完整新闻概括」+ 下方「新闻详细内容」 |
| 弹窗关闭 | 点击空白区域 / 右上角按钮 / `Esc` 均可关闭；打开时锁定背景滚动（含滚动条宽度补偿） |
| 阅读完成 | 每条「阅读完成 ⇄ 已完成」双向切换，卡片右上角渐变对勾；5 条状态**相互独立** |
| 本地保存 | 阅读状态写入 `localStorage`，**刷新后自动恢复**（隐私模式下自动降级为内存态） |

### 进度与闭环
| 功能 | 说明 |
| --- | --- |
| 分段式进度 | 吸顶极简进度条改为 **5 个点**，读完一个点亮一个，可点击跳转到对应新闻 |
| 完成态反馈 | 5 条全部读完，页底浮现「今日 5 条已读完」+ 明日预告，给日报一个闭环 |
| 回到顶部 | 右下角悬浮圆钮，滚动 >320px 淡入，点击平滑回顶（rAF 节流） |

### 延伸阅读 · 数据附录（轻视觉层级）
| 模块 | 说明 |
| --- | --- |
| 报告信息栏 | 报告日期、采编维度、本期导语，下移至新闻之后 |
| 行业三大趋势 | 技术 / 市场 / 应用三张统一小卡 |
| 今日行业热度指数 | 86/100 数值 + 升降胶囊 + 刻度条 + 细分指标 |
| 重点关注预警 | 合规窗口期收窄 / 推理价格战 / 端侧算力竞争 |
| 领域分布统计 | 由 5 条资讯 `domain` 字段**自动聚合**渲染 |
| 本期小结 + 数据更新信息 | 总结段 + 关键词 + 更新时间戳（自动生成为当前时间） |

### 进阶交互
| 功能 | 说明 |
| --- | --- |
| 阅读模式 | 右上角一键切换沉浸纯文本态（无装饰、大字号、仅留时间轴新闻） |
| 右侧圆点导航 | 5 个新闻点 + 1 个附录点，随滚动高亮当前区域（≤900px 隐藏） |
| 暗色模式 | 仅按系统 `prefers-color-scheme` 自动切换，无手动开关 |
| 键盘可达 | `Enter`/`Space` 打开、`Esc` 关闭，焦点管理与滚动锁定完整保留 |
| 动效 | 新闻卡 stagger 依次入场（~70ms）；hover 方向性位移 + 色条伸展；节点进入视口点亮；弹窗淡入淡出；`prefers-reduced-motion` 自动降级 |

## 四、使用方法

### 1. 直接打开（最简单）
双击 `index.html`，即可在浏览器中离线运行。

### 2. 本地静态服务（可选）
```bash
# 任选其一，在文件所在目录执行
python3 -m http.server 8080
# 或
npx serve .
```
然后访问 `http://localhost:8080`。

### 3. 自定义日报内容
打开 `index.html`，找到 `<script>` 顶部的 `NEWS` 数组，每条结构如下（**字段语义保持不变**，仅新增 `heat` 与 `note` 并带默认值兜底）：

```js
{
  id: 'r1',            // 唯一标识（阅读状态按此持久化）
  domain: '大模型',     // 领域标签（同时驱动「领域分布统计」）
  source: '综合科技媒体',
  time: '08:30',       // 时间刻度，渲染时按此从早到晚排序
  heat: 92,            // 热度指数（0-100，编辑标注，用于卡片热度可视化）
  metric: '部署成本 ↓ 46%',  // 核心数据标注
  title: '完整标题',
  one: '一句话超短总结',     // 列表 / 速览 / 时间轴展示
  note: '编辑视角一句话',    // 编者按（缺省有兜底文案）
  summary: '完整新闻概括',
  detail: { paras: ['段落一', '段落二'], points: ['要点一', '要点二'] }
}
```

### 4. 调整视觉风格
所有设计变量集中在 `:root`：
- `--anchor` / `--anchor-2`：锚点色（电光紫）及其深色，改这里即换主色。
- `--serif` / `--sans` / `--mono`：标题（衬线）、正文（无衬线）、数字时间（等宽）字体栈。
- `--paper` / `--ink` / `--radius` / `--shadow`：底色、文字、圆角、投影。
- `@media (prefers-color-scheme: dark)`：暗色模式变量在此覆盖。

## 六、后续扩展建议

1. **数据驱动渲染**：将 `NEWS` 数组改为从本地 JSON / 接口加载，支持多期归档与历史回看。
2. **日报归档**：按日期路由不同期号，提供「往期」列表与深链分享。
3. **导出长图**：基于 `html-to-canvas`（需引入，会破坏零依赖）或手动排版生成封面图，便于社媒分发。
4. **RSS / 资讯源接入**：定时拉取公开资讯，自动生成 `NEWS` 草稿，人工审核后发布。
5. **阅读统计可视化**：把分段进度升级为「本周连续阅读」打卡，增强用户回访。
6. **无障碍增强**：为时间轴节点与进度点补充 `aria-current`、为弹窗补充焦点陷阱（focus trap）。
7. **多锚点色主题**：内置电光紫 / 酸性青柠 / 荧光珊瑚三套主题，按 `data-theme` 切换（仍不加手动暗色开关）。
8. **热词标签云**：从 `domain` 与 `note` 抽取关键词，做轻量 tag 云（保持克制，不喧宾夺主）。

## 七、设计说明（关键结构决策）

代码中以注释标出关键结构决策，例如：

- `/* 新闻主体：纵向时间轴（按 time 从早到晚） */` —— 主体改为叙事性时间轴。
- `/* 今日速览（日报目录；点击直接打开弹窗） */` —— 首屏目录，5 秒建立全局感。
- `/* 分段式阅读进度（吸顶极简形态） */` —— 5 个点替代长条。
- `/* 编辑视角：斜体 + 左侧色条 + 小标签 */` —— 内容层差异化。
- `/* 延伸阅读 · 数据附录（轻视觉层级） */` —— 其余模块下沉、减淡。
- `/* 现代背景：纯色底 + 一处大模糊光斑 + 极细网格 + 细微噪点 */` —— 背景不抢内容。
- `/* 暗色模式：仅按系统偏好自动切换，不加手动开关 */`。
